## 40, 41, 42 matrix

Each measure passes on its own with **>50% Yes** statewide. **41 and 42 do not conflict with each other** and can both take effect together. **40 conflicts with 41 and with 42**; if two or more of those pass, **more Yes votes on the conflicting measure wins** on those parts (courts could still litigate overlap).

| Prop 40 | Prop 41 | Prop 42 | Side effect |
| ------- | ------- | ------- | ----------- |
| No pass | No pass | No pass | **Status quo.** No billionaire wealth tax. No new 41 audits/spending-limit rules on voter-approved state special taxes. State can still enact new taxes on personal property (e.g. financial assets) and some retroactive taxes, subject to existing law. **Does not change Prop 13 property tax bills.** |
| Pass | No pass | No pass | **One-time ~5% tax on net worth ≥ ~$1B** (directly held homes excluded from that tax). Revenue mainly for health care. **Middle-class homeowners are not taxed by 40.** No 41/42 guardrails. |
| No pass | Pass | No pass | **No billionaire tax.** New voter-approved **state special taxes** face **audits** and **cannot be excluded from the state spending limit** the way 40’s revenue would be. **No new 42 ban** on state personal-property or retroactive taxes. |
| No pass | No pass | Pass | **No billionaire tax.** **New state taxes on owning personal property** (stocks, savings, etc.) **blocked**; **retroactive state tax hikes** limited. **Home assessed value / Prop 13 bill unchanged** (42 is not a home-equity or property-tax cut). |
| No pass | Pass | Pass | **No billionaire tax.** **41 + 42 both apply** (tax limits/audits plus personal-property and retroactive-tax bans). Strongest **state-level** “limit new taxes” outcome in this trio. |
| Pass | Pass | No pass | If **both pass**: **whichever of 40 or 41 has more Yes votes** prevails on conflicting parts. **40 wins** → billionaire tax, 41’s conflicting limits void. **41 wins** → no billionaire tax, 41 rules apply. |
| Pass | No pass | Pass | If **both pass**: **whichevehas more Yes votes** prevails on conflicting parts. **40 wins** → billionaire tax; **42’s ban on new state asset taxes does not** (on conflicting parts). **42 wins** → no billionaire tax; asset/retroactive guardrails apply. **Middle-class property tax bill still not set by 40/42.** |
| Pass | Pass | Pass | **All three pass as measures**, but **40 vs 41** and **40 vs 42** are decided separately by **Yes vote totals**. Typical outcomes: **40 tops both** → billionaire tax only (41/42 conflicting parts void). **41 and/or 42 beat 40** → no billionaire tax; **41 and 42 can both remain in effect** if each outpolls 40. |
